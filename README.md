# PS1-Memory
This app is a memory game with card images about the first PlayStation.

## Description
This is my fifth android app and is the last one of this amazing year. I learned so much about C# and app developing, that I couldn't believe it when I started to study C#.
This app is memory game with images referring to games and accessories of the first PlayStation. Choose the level difficulty (easy, medium and hard) and find all the card pairs. Pay attention to the particular sound played for some card pairs. Enjoy the initial and more stable animation and the 3 random background musics. Can you recognize all of them?

## Properties
- Download and install the .APK file on your device.
- The app runs on Android systems only.
- The app is performed for smartphones, but it also runs well on tablet.
- This app has been tested with VirusTotal. Results are at the page bottom.
